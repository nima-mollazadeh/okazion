# اکازیون — EKAZION

فروشگاه آنلاین فرصت‌های ویژه — نمونهٔ نمایشی فرانت‌اند (بدون بک‌اند). با تم تیره و اکسنت نارنجی.

«هر روز، یک فرصت تازه.»

## اجرا

```bash
npm install
npm run dev        # اجرای محلی روی http://localhost:5173
npm run build      # ساخت نسخهٔ نهایی در dist
npm run preview    # پیش‌نمایش نسخهٔ ساخته‌شده
```

## ساختار پروژه

```
src/
├── data/                  ← همهٔ محتوای فروشگاه (برای جایگزینی با دادهٔ واقعی فقط همین‌جا را عوض کنید)
│   ├── products.js        ← کاتالوگ ۲۶ محصولی
│   ├── categories.js      ← ۸ دسته‌بندی
│   ├── brands.js          ← برندها و هنرمندان
│   ├── slides.js          ← اسلایدهای بنر اصلی
│   ├── instagram.js       ← شبکهٔ اجتماعی
│   └── orders.js          ← سفارش‌های نمونهٔ صفحهٔ حساب
├── context/ShopContext.jsx ← سبد خرید، علاقه‌مندی‌ها و توست‌ها (با localStorage)
├── lib/format.js           ← اعداد و قیمت‌های فارسی (Intl fa-IR)
├── components/
│   ├── layout/            ← هدر دسکتاپ/موبایل، منوها، سبد کشویی، ناوبری پایین، فوتر
│   ├── home/              ← اسلایدر، برندها، دسته‌ها، بنر هدیه، چرا سبزینه، اینستاگرام
│   ├── product/           ← کارت محصول و کروسل افقی
│   ├── shop/              ← پنل فیلترها و مرتب‌سازی
│   └── ui/                ← اجزای پایه (دکمه، قیمت، نشان، لوگو و…)
└── pages/                 ← خانه، فروشگاه، محصول، سبد، حساب، درباره، ۴۰۴

scripts/generate-images.mjs ← مولّد تصویرسازی‌های SVG برند (۵۳ تصویر)
public/images/              ← خروجی تصاویر (تولیدشده؛ قابل بازتولید با node scripts/generate-images.mjs)
```

## نکته‌ها

- **تصاویر**: همهٔ تصاویر سایت، تصویرسازی‌های اختصاصی SVG در پالت سبزینه‌اند؛ سریع، سبک (کل مجموعه ~۲۲۰KB) و بدون وابستگی به اینترنت. برای بازتولید: `node scripts/generate-images.mjs`
- **داده‌ها**: ساختار مرکزی در `src/data` — جایگزینی محصولات واقعی نیازی به تغییر کامپوننت‌ها ندارد
- **سبد خرید و علاقه‌مندی‌ها** در localStorage ذخیره می‌شود؛ آستانهٔ ارسال رایگان ۱٬۰۰۰٬۰۰۰ تومان است (`src/lib/format.js`)
- **تکنولوژی**: React 19 + Vite + Tailwind CSS v4 + Vazirmatn (فونت متغیر محلی) + lucide-react
- کاملاً راست‌به‌چپ و فارسی؛ اعداد و قیمت‌ها با `Intl.NumberFormat('fa-IR')`
