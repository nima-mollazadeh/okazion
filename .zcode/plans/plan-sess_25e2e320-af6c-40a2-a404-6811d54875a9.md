# سبزینه (SABZINEH) — Premium Persian E-commerce Prototype

## Summary
Greenfield React SPA in `C:\Users\NiMA\Desktop\pr` — fully RTL, Persian-only, no backend. A premium boutique feel built on the given green palette, Vazirmatn typography, Lucide icons, and custom lightweight sliders (no heavy carousel libraries). All content flows from one centralized data layer so products/brands/slides can be swapped later without touching components. The Cat Map's hierarchy (brands → featured → best sellers → newest, brand-attributed product cards) inspires the structure; all visuals are original Sabzineh identity.

*Note: the referenced screenshot is not in the workspace, so mobile composition follows the written description: announcement bar → hamburger/centered logo/bag → rounded search → rounded cards → 5-item bottom nav.*

## 1. Stack & Scaffolding
- `npm create vite@latest . -- --template react` (JavaScript)
- Dependencies: `react-router-dom`, `lucide-react`, `vazirmatn` (local woff2 font — offline-safe), `tailwindcss` + `@tailwindcss/vite` (Tailwind v4, CSS-first config)
- `index.html`: `lang="fa" dir="rtl"`, title «سبزینه | چیزهای کوچک برای زندگی زیباتر», theme-color `#2F6B4F`, SVG leaf-mug favicon
- Route-level code splitting via `React.lazy`

## 2. Design System (`src/index.css`)
- `@theme` tokens: bg `#F7F8F3`, primary `#2F6B4F`, dark `#1F4635`, soft `#DCE9DF`, accent `#EEF4EA`, text `#17221C`, muted `#6F786F`, hairline border tone
- Vazirmatn (weights 100–900) loaded locally from the npm package
- Large radius scale (xl/2xl/3xl), one very soft shadow token, 1px subtle borders, generous whitespace
- Motion: 150–300ms ease-out transitions, subtle scroll-reveal via IntersectionObserver, `prefers-reduced-motion` respected
- RTL via `dir="rtl"` + logical utilities (`ms-/me-/ps-/pe-/start-/end-`); helpers: scrollbar-hide, no tap-highlight, focus-visible rings

## 3. Data Layer (centralized, replaceable)
- `src/data/products.js` — ~26 products; schema `{ id, slug, name, brand, category, price, oldPrice, images[], isNew, isBestSeller, rating, sold, description, features[], specs{} }` (includes the 8 named featured products)
- `data/categories.js` (8), `data/brands.js` (6 fictional), `data/slides.js` (3 hero slides), `data/instagram.js` (6), `data/orders.js` (sample)
- `src/lib/format.js` — Persian numerals & prices via `Intl.NumberFormat('fa-IR')` + «تومان»
- `src/context/ShopContext.jsx` — cart, favorites, toasts; localStorage persistence; free-shipping threshold ۱٬۰۰۰٬۰۰۰ تومان

## 4. Shared Components (`src/components/`)

- **BrandShowcase** «برندها و هنرمندان منتخب» — 6 minimal wordmark blocks; desktop row, mobile snap-scroll
- **CategoryGrid** «چی دوست داری؟» — 8 categories, 4-col desktop / 2-col mobile, rotating soft-green tints, image + title + hover interaction
- **ProductCard** — image with hover zoom, favorite heart, quick add-to-cart, name/brand/price, discount % badge, «جدید» badge, compact-but-readable mobile variant
- **ProductCarousel** «پرفروش‌ترین محصولات» — snap scroll, desktop arrows, «مشاهده همه»
- **PromoBanner** — asymmetric editorial split, gift headline + CTA «کشف مجموعه هدیه»
- **WhySabzineh** — 4 benefits with Lucide line icons (ارسال سریع / بسته‌بندی خاص / محصولات منتخب / پشتیبانی واقعی)

- **Footer** — brand + tagline, shop links, customer-service links, Instagram/Telegram (Send icon)

- **CartDrawer** (slides from left in RTL) + **Toasts** + `ui/` primitives (Button, Badge, QtyStepper, Price, SectionHeader, SmartImage with branded SVG fallback)

## 5. Pages (react-router)
- `/` Home: HeroSlider → Brands → Categories → «محبوب‌ترین‌ها» grid (4/3/2 cols) → «پرفروش‌ترین‌ها» carousel → PromoBanner → «تازه‌رسیده‌ها» with «جدید» badges → WhySabzineh → Instagram → Footer
- `/shop` — desktop sidebar filters vs mobile sticky «فیلترها»/«مرتب‌سازی» toolbar opening bottom sheets; category chips, brand multi-select, price range, sort (جدیدترین/محشب‌ترین/پرفروش‌ترین/ارزان‌ترین/گران‌ترین); URL-synced params (q, cat, sort); search box; result count; empty state
- `/product/:slug` — large swipeable gallery + thumbnails, title/brand/rating, price + discount + savings, availability, quantity stepper, «افزودن به سبد» / «خرید سریع», favorite, توضیحات/مشخصات/ارسال و مرجوعی sections, related products carousel, breadcrumb
- `/cart` — line items with qty/remove, subtotal, shipping (free above threshold), total, «ادامه خرید» + «ثبت سفارش» (elegant order-success state), empty state
- `/account` — profile, sample orders, live favorites, addresses
- `/about` — compact brand story (target of «درباره ما» links) · `404` page

## 6. Images
- Curated real photography (mugs, ceramics, desk accessories, plants, cozy interiors) downloaded into `public/images/`, each URL verified HTTP 200 at build time; `SmartImage` falls back to a branded SVG placeholder on error
- Contingency: if the network is unavailable, generate polished SVG product illustrations in the Sabzineh palette instead (cohesive illustrated-boutique identity)
- All images lazy-loaded, aspect-ratio locked (no CLS), reasonably sized

## 7. Responsive & Performance
- Breakpoints: 360–767 / 768–1023 / 1024+ / 1440+; dedicated mobile composition (not shrunken desktop); zero horizontal overflow; ≥44px touch targets
- Local font + local images, no animation libraries, route-level code splitting, minimal dependency footprint
